What is FAIR data?

FAIR data can be found, accessed, understood by software, and reused. Clear files and a record of how they were processed help others check your results and help you return to an experiment later.

Findable
Give the dataset a descriptive title, searchable metadata, and a persistent identifier such as a DOI.
Accessible
Store it in a repository with clear access conditions. Restricted data can also follow FAIR principles.
Interoperable
Use readable formats, explicit units, and recognised identifiers for samples and compounds.
Reusable
Explain the experiment, processing steps, and permitted uses through metadata, provenance, and a license.

What GeckoPlotter includes

The package contains your imported data as CSV, original files where available, peak results, figures, and a readable report. Linked metadata records settings such as smoothing, calibration, and edits made in this workspace. Unchanged tables are stored once.

Open report.html first. Add the experimental details that the source files cannot supply. Analysis code is optional under Repository details; the data and edit history are included in every package.

Before sharing

Review the files, add authors and a license, and deposit the dataset in a suitable repository. Reserve its DOI and include it in the README. A local ZIP prepares the material; the repository makes it discoverable and manages access.
